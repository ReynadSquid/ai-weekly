# Формат выпуска

> Это шаблон по умолчанию из ТЗ. Замените разделы на свой формат A–G —
> редактор и нарезчик читают его каждый запуск. Ключи разделов (A, B, …)
> должны совпадать с полем `section` в config/watchlist.yaml.

## Заголовок

`<b>{title} #{number} · {date_range}</b>`, затем пустая строка и 3 главных
события недели — по одной строке каждое, маркер «•».

Если у выпуска есть обложка, в подпись к ней идёт только первая строка
(«AI Weekly #N · даты»), а 3 события не публикуются — их заменяют логотипы на обложке.
Без обложки шапка выходит целиком первым постом.

## Разделы

| Ключ | Эмодзи | Название | Что входит |
|------|--------|----------|-----------|
| A | 🏢 | Лидеры рынка | OpenAI, Anthropic, Google, Meta, Microsoft, xAI |
| B | 🧩 | Второй эшелон | Mistral, DeepSeek, Qwen, Perplexity, Apple, Amazon |
| C | 🖥 | Инфраструктура и железо | NVIDIA, AMD, облака, дата-центры, сделки |
| D | 🎨 | Креативные и dev-инструменты | Midjourney, Runway, ElevenLabs, Cursor, Suno |
| E | 🚀 | Новое вне списка | Продукты и стартапы недели вне контрольного списка |
| F | 🔬 | Исследования и open-source | Статьи, open-source модели, бенчмарки, инструменты |
| G | 👂 | Слухи | Только статус rumor, формулировка «по данным …» |

Пустые разделы не выводятся. Судебные и регуляторные события идут в раздел
компании, которой касаются; если компании нет — в E.

## Новость

```
<b>Заголовок новости</b>
1–3 предложения сути своими словами.
<i>Почему важно:</i> одно предложение.
<a href="URL первоисточника">Источник</a>
```

В разделе G перед текстом — «По данным {кто}: …».

## Финал

Только хэштеги компаний, упомянутых в выпуске (из config/watchlist.yaml), плюс `#AIWeekly`.
Строки-вывода недели («Итог недели: …») нет.

Под каждым сообщением выпуска скрипт нарезки сам ставит строку хэштегов: компании, чьи новости
есть в этом сообщении (по порядку появления), и `#AIWeekly`. Хэштеги из подвала редактора при этом
убираются, в разделах их писать не нужно. В подписи к обложке — только `#AIWeekly`.

## Стиль

- Русский язык, нейтральный тон, без рекламных эпитетов («революционный»,
  «невероятный») и без собственных оценок, которых нет в источнике.
- Англоязычные названия продуктов и моделей не переводятся.
- Эмодзи — только маркер раздела, не больше одного на раздел.
- Цифры бенчмарков — с указанием, кто их заявил («по данным компании»).
- Только HTML-теги Telegram: b, i, u, s, a, code, pre, blockquote.
