**AI Weekly #1 · 18–25 октября 2026**

• Anthropic передала стандарт Agent Skills фонду при Linux Foundation
• Anthropic запустила превью персонального агента Claude Duet
• Модели OpenAI стали доступны через Google Cloud

## 🏢 Лидеры рынка

**Anthropic передала стандарт Agent Skills фонду AAIF**
Anthropic отдала открытый стандарт Agent Skills фонду Agentic AI Foundation при Linux Foundation, вместе с названием, логотипом, GitHub-организацией и доменом agentskills.io. По данным Anthropic, стандарт интегрировали более 70 платформ (среди них ChatGPT, Cursor, GitHub Copilot, VS Code), опубликован 1 млн навыков, установок почти 280 млн.
*Почему важно:* за стандартом теперь стоит фонд при Linux Foundation, а не одна компания.
[Источник](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

**Claude Duet: персональный агент от Anthropic**
На этой неделе Anthropic представила Claude Duet — проактивного агента на Opus 5.5: он принимает задачи сообщениями, продолжает работать в фоне и спрашивает подтверждения, когда это важно. Это research preview в приложениях для iOS и Android и в вебе на claude.ai; по данным компании, доступ по листу ожидания только для планов Pro и Max в США, Team и Enterprise пока не включены.
*Почему важно:* попробовать агента пока могут лишь подписчики Pro и Max в США.
[Источник](https://claude.com/product/claude-duet)

**Модели OpenAI появятся в Google Cloud**
21 октября OpenAI и Google Cloud объявили, что передовые модели OpenAI доступны через Model Garden и продаются через Google Cloud Marketplace; клиенты могут направить на них свои обязательства по расходам в Google Cloud. Модели также планируются в Antigravity и Gemini Agent / Gemini Enterprise. По данным Olhar Digital, локальные Codex CLI и Desktop смогут обращаться к платформе Gemini для инференса.
*Почему важно:* клиенты Google Cloud могут покупать модели OpenAI в рамках уже действующих расходных обязательств.
[Источник](https://9to5google.com/?p=734157)

**OpenAI меняет среду обучения frontier-моделей**
По данным TechCrunch, OpenAI заявила, что будет обучать frontier-модели без доступа к живому интернету, на кэшированных и индексированных копиях веба. Компания считает, что должна всегда мочь не допустить несанкционированного произвольного доступа модели к живому интернету.
*Почему важно:* из обучения frontier-моделей OpenAI убирается живой интернет.
[Источник](https://techcrunch.com/2026/10/23/openai-says-it-will-no-longer-train-its-ai-models-on-the-live-internet-citing-significant-risks/)

**Anthropic направит 5% акций в Public Benefit Fund**
По данным компании, Anthropic выделяет 5% акций новому Public Benefit Fund при условии одобрения акционеров. По решению совета доля может вырасти ещё на 2% за каждые 50% роста стоимости выше базовой отметки. С прежними обязательствами основателей и сотрудников на общественные цели пойдёт около 20% акций.
*Почему важно:* заметная доля капитала Anthropic закрепляется за общественными целями.
[Источник](https://www.anthropic.com/news/public-benefit-fund)

**Decisions API от OpenAI стал доступен всем клиентам**
По данным TechCrunch, 22 октября OpenAI открыла Decisions API для всех клиентов и добавила в публичную версию голосовую и визуальную модальности. Впервые API показали на developer day 29 сентября.
*Почему важно:* теперь API может использовать любой клиент OpenAI, причём не только с текстом.
[Источник](https://techcrunch.com/2026/10/22/openai-makes-its-jev-competitor-widely-available-as-decision-model-competition-heats-up/)

**Реклама в ChatGPT вышла ещё в 26 странах**
По данным OpenAI (через Reuters и The Next Web), 21 октября реклама в ChatGPT расширилась на 26 стран, всего их стало 89. Более 100 000 рекламодателей запускали кампании. Реклама показывается на планах Free и Go; Plus, Pro и Enterprise без неё.
*Почему важно:* пользователи Free и Go в новых странах увидят рекламу, платные планы остаются без неё.
[Источник](https://thenextweb.com/news/chatgpt-ads-89-countries-100000-advertisers)

## 🧩 Второй эшелон

**Mistral выпустила речевые модели Voxtral 3**
В семейство Voxtral 3 входят Small Transcribe 3, Mini Transcribe 3, Mini Transcribe Realtime 3 и Mini TTS 3; транскрипция поддерживает более 50 языков. По данным компании, транскрипция стоит от $0,0035 за минуту, TTS — $13 за 1 млн символов. Также вышел SDK голосовых агентов на LiveKit: речь, рассуждение и речь в едином потоковом конвейере.
*Почему важно:* разработчики голосовых агентов получили набор моделей и SDK с опубликованными ценами.
[Источник](https://mistral.ai/news/voxtral-3/)

**Perplexity Computer можно запускать локально на Mac**
По данным компании, Perplexity Computer теперь работает локально в приложении Perplexity для Mac. Нужен Mac на Apple silicon, рекомендуется 36 ГБ памяти и больше; используются модели Qwen 3.6 и PPLX Pro (дообученная версия Qwen). Доступно подписчикам Pro, Max и Enterprise.
*Почему важно:* подписчики с подходящим Mac могут запускать Computer на своём устройстве.
[Источник](https://www.perplexity.ai/hub/blog/perplexity-computer-now-runs-fully-local-on-mac)

**DHS запретил DeepSeek в федеральных гражданских ведомствах США**
По данным TechCrunch и BleepingComputer, приказ DHS обязывает федеральные гражданские ведомства прекратить закупки продуктов DeepSeek и удалить их из ИТ-систем. Он касается и продуктов аффилированных лиц, и сторонних продуктов на технологии DeepSeek; можно запросить исключения. Приказ опубликован в Federal Register 20 октября.
*Почему важно:* ограничение действует для федеральных гражданских ведомств и не является общим запретом на частное использование.
[Источник](https://techcrunch.com/2026/10/20/us-orders-federal-agencies-to-remove-chinas-deepseek-ai-from-their-systems/)

## 🖥 Инфраструктура и железо

**Google Cloud и NVIDIA: инстансы A5X на Vera Rubin**
По данным NVIDIA, Google Cloud и NVIDIA объявили инстансы A5X на Vera Rubin NVL72 с ConnectX-9 SuperNIC, сетью Virgo Network и жидкостным охлаждением 4-го поколения. *Почему важно:* клиентам Google Cloud платформа Vera Rubin станет доступна в облаке.

## 🚀 Новое вне списка

**Moonshot AI выпустила Kimi K3.1 Pro**
На этой неделе вышла Kimi K3.1 Pro с контекстом 1 млн токенов и вариантом Highspeed, который, по заявлению компании, в 2–3 раза быстрее. По данным Moonshot, на Terminal-Bench 4.0 модель набрала 65,7% (Opus 5.5 — 66,4%, GPT-6 Astra — 58,2%), а доля галлюцинаций на Kimi Hallu Bench Hard упала с 23,4% у K3 до 8,3%. Полные веса обещаны к 4 ноября 2026; для открытой версии убрали данные по кибербезопасности.
*Почему важно:* веса пока только обещаны, а приведённые цифры — замеры самой компании.
[Источник](https://www.kimi.ai/blog/kimi-k3-1-pro)

**Canva выпустила модель генерации изображений Craft**
По данным TechCrunch, Canva представила первую собственную модель генерации изображений Canva Craft: до 2K в 30 соотношениях сторон, обучена на дизайнерских шаблонах. Она доступна всем в Dream Lab и через Canva API; поддержку в ChatGPT и Gemini через MCP планируют, а облегчённые Craftfast и Craft-ultrafast обещаны «скоро».
*Почему важно:* модель уже доступна всем пользователям Dream Lab и разработчикам через API.
[Источник](https://techcrunch.com/2026/10/22/canva-releases-its-first-image-generation-model/)

**Block показала речевую модель Dessa**
На этой неделе Block представила Dessa — полнодуплексную speech-to-speech модель, обученную с нуля только на человеческой речи. По заявлению Block, она работает локально на MacBook Pro M4 Max или мощнее и обучена на одной стойке NVIDIA GPU. Публичного доступа нет: лист ожидания и ранний доступ для исследователей безопасности ИИ.
*Почему важно:* попробовать модель пока могут только участники раннего доступа.
[Источник](https://block.xyz/dessa)

**1Password for Agents: вход для агентов без доступа к паролям**
По данным компании, 22 октября 1Password анонсировала 1Password for Agents: агент подтверждается уникальным цифровым ключом, пользователь одобряет запрос на своём устройстве, а 1Password подставляет данные в форму входа, и агент их не получает. Среди партнёров — Claude Duet, ChatGPT Work, dots, Muse (Meta), Grok Bot, Town, Browserbase, Browser Use, Perplexity, Ramp.
*Почему важно:* решение о входе принимает пользователь, а пароль агенту не передаётся.
[Источник](https://1password.com/press/2026/october/1password-for-agents-trust-layer-personal-ai-agents)

## 🔬 Исследования и open-source

**RecursiveSI опубликовала модель flint для работы с кодом**
flint — MoE-модель на 39,8B параметров, около 2,5B активны на токен, контекст 262 144 токена, лицензия Apache 2.0. Она рассчитана на поиск багов, правки, тесты и многошаговые вызовы инструментов. По данным разработчика, SWE-bench Verified — 74,2%, SWE-bench Pro v2 — 89,7%, Terminal-Bench 2.1 — 54,9%; методики сравнений различаются.
*Почему важно:* модель с лицензией Apache 2.0 при малом числе активных параметров нацелена на задачи с кодовой базой.
[Источник](https://huggingface.co/RecursiveSI/flint)

**IBM выпустила три речевые модели Granite**
IBM опубликовала под Apache 2.0 модели granite-speech-5.0-2b, обновлённую granite-speech-5.0-470m-turboctc и granite-speech-4.1-2b-plus. По заявлению IBM, 5.0-2b — №2 среди открытых ASR-моделей по среднему WER на английском (5,06%), а Turbo CTC ускорилась примерно с 12 600 до 19 870 RTFx. Для 2B-модели заявлена поддержка Transformers, vLLM, llama.cpp и mlx-audio.
*Почему важно:* открытые речевые модели можно запускать в распространённых инструментах инференса.
[Источник](https://huggingface.co/blog/ibm-granite/granite-speech-5)

**NVIDIA и Kumo: Kumo Relational предсказывает по реляционным базам без обучения**
Kumo Relational — фундаментальная модель для предсказаний по реляционным БД без обучения под задачу; код под Apache 2.0, веса под OpenMDW License 1.1. По данным NVIDIA и Kumo, на классификации RelBench V1 она в среднем почти на 4 пункта AUROC опережает градиентный бустинг на ручных признаках, а на SAP SALT на 8% по MRR обходит ансамбли AutoGluon. Авторы отмечают, что на очень больших обучающих выборках специализированные модели могут быть лучше.
*Почему важно:* для части задач на реляционных данных не нужно обучать отдельную модель.
[Источник](https://huggingface.co/blog/nvidia/kumo-relational)
